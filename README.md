# 🎬 Clone Netflix

Uma recriação da interface da **Netflix**, desenvolvida para fins educacionais com foco na prática de **HTML5**, **CSS3** e **JavaScript**. O projeto busca reproduzir o visual da plataforma de streaming, aplicando conceitos modernos de desenvolvimento front-end e responsividade.

> **Aviso:** Este projeto foi desenvolvido exclusivamente para estudos e não possui qualquer vínculo com a Netflix. As marcas e logotipos pertencem aos seus respectivos proprietários.

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/eijhenyfer/clone-netflix.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
